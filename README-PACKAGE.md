# PocketPHP Framework

A lightweight, fast, and easy-to-use PHP framework for building web applications.

## Installation

You can create a new PocketPHP project using Composer:

```bash
composer create-project pocketphp/pocketphp your-project-name
```

This will create a new project with the latest version of PocketPHP.

## Requirements

- PHP 8.2 or higher
- Composer
- MySQL 5.7+ or MariaDB 10.3+
